Don't create a separate `.nix` file per app (too small); group app config into shared topic files (`modules/home/default.nix` for cross-platform home-manager, `modules/common/darwin.nix` for darwin-only apps and cask settings), keep raw config files in a data directory beside them (e.g. `modules/home/ghostty/config`), and reserve dedicated `.nix` files for broad topics like `git/`, `shell/` or `linux.nix`.
