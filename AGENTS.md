Group small app config into shared topic files (`modules/home/default.nix` for cross-platform home-manager, `modules/darwin/default.nix` for darwin-only apps and cask settings, `desktop.nix` for desktop apps with no files of their own). An app that has a folder of config files gets a `default.nix` in that folder, imported from `desktop.nix` (e.g. `modules/home/ghostty/`, `rex/`, `zed/`). Assets shared with system modules, like fonts and images, go in top-level `assets/`. Reserve dedicated top-level `.nix` files for broad topics like `git.nix` or `gnome.nix`.
Keep comments sparse: add one only when it carries information that isn't obvious from the code (the why, a gotcha, a magic value), never to restate what the code does or to label sections.
